Privacy Policy

Last updated: 28 October 2026

"Reel Rasam publisher" is a private tool used only by the owner of the Reel Rasam channels (Instagram @_reelrasam, YouTube @reel_rasam) to publish its own original videos and images.

What the tool accesses

With the owner's permission, it uses the YouTube Data API (scope youtube.upload) and the Instagram API only to upload content to the owner's own accounts. It does not read, collect, store or share data about viewers or any other users.

Data storage

Access tokens are stored as encrypted secrets in the owner's own GitHub repository settings and are used only to publish posts the owner has approved. No personal data is sold or shared with third parties.

Revoking access

Access can be revoked at any time from your Google Account (Security → Third-party access) or Instagram (Settings → Apps and websites).

Contact

Message @_reelrasam on Instagram.

Use of information received from Google APIs adheres to the Google API Services User Data Policy.
